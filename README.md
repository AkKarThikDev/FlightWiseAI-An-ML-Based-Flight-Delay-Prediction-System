# FlightWise AI — Streamlit application

## 1. Copy the files
Copy `app.py` and `requirements.txt` into the root of your existing FlightWise_AI project.
The app expects the model bundle generated by Notebook 07 at:

`models/flightwise_deployment_bundle.joblib`

Do not rename or move that bundle.

## 2. Activate your existing virtual environment (PowerShell)
```powershell
cd "C:\my prsnl\Luminar\Luminar_Project\FlightWise_AI"
.\.venv\Scripts\Activate.ps1
```

## 3. Install dependencies
```powershell
python -m pip install -r requirements.txt
```

## 4. Start Streamlit
```powershell
python -m streamlit run app.py
```

Streamlit will print a local URL, usually `http://localhost:8501`.

## Notes
- The app loads the Random Forest deployment bundle from Notebook 07.
- It uses the bundle's fitted preprocessor, exact selected feature order, and saved threshold.
- Airline and airport dropdown values are read from the fitted OneHotEncoder categories.
- Feature formulas and bins mirror Notebook 04.
- No retraining occurs in the app.
- The app is not connected to live airline, airport or weather services.
